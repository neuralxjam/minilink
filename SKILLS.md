# Skills

## Installed via plugins (see `setup.md` for the install commands)

- **`claude-code-setup`** — project bootstrap and convention helpers
- **`superpowers`** — extended toolkit for power-user automation
- **`ui-ux-pro-max`** — UI/UX design and component-building helpers (used when building the HTMX dashboard)

## When to invoke

| Task | Skill |
|---|---|
| Designing the dashboard UI / HTMX components | `ui-ux-pro-max` |
| Setting up a new convention or scaffolding a new file pattern | `claude-code-setup` |
| Power-user automation (multi-file refactors, batch edits) | `superpowers` |
| Writing a Dockerfile or Compose file from scratch | (no skill — Claude inline; this is intentional, the learning is the point) |
| Writing the GitHub Actions workflow | (no skill — Claude inline) |
